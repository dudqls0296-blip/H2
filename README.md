# 📰 인덕대학교 언론부 2026 연말 매거진 웹진 (INDUK PRESS)

> **"학우의 시선으로 캠퍼스를 밝히고, 시대의 목소리를 기록합니다."**  
> 인덕대학교 언론부(학보사·방송국·미디어센터)의 2026년 한 해를 총결산하는 연말 특집 디지털 매거진 및 기사 제작/관리 시스템입니다.

---

## 🌟 주요 특징 및 구성

### 1. ✍️ 연말 잡지 기사 제작/작성 폼 (Magazine Editor Form)
* **간편한 신규 기사 등록**: 상단 `[기사 작성 / 제작 폼]` 버튼 또는 우하단 플로팅 버튼을 클릭하여 언제든 새 기사를 작성할 수 있습니다.
* **풍부한 기사 메타데이터**:
  - 카테고리 (커버 스토리, 캠퍼스 보도, 인덕 피플, 문화 & 라이프, 포토 에세이, 언론부 후기 등)
  - 기사 제목(Headline) & 부제목(Sub-headline)
  - 기자 바이라인 (기자명, 소속 학과/부서)
  - 발행일자 및 예상 독서 소요시간
  - 표지 커버 스토리(Hero Cover) 지정 옵션
* **3가지 방식의 대표 이미지 등록**:
  1. 외부 이미지 URL 직접 입력
  2. 내 컴퓨터의 이미지 파일 직접 첨부 (Base64 자동 변환으로 서버 없이 즉시 렌더링)
  3. 인덕대/캠퍼스 분위기에 최적화된 엄선된 테마 사진 프리셋 8종 원클릭 선택
* **원클릭 서식 도구 툴바**:
  - `+ 소제목` : 잡지 스타일의 볼드 소제목 태그 삽입
  - `+ 단락` : 본문 문단 삽입 (첫 문단 드롭캡 적용)
  - `+ 강조 인용구` : 우아한 버건디 라인과 이탤릭 서체 인용구 삽입
  - `+ 사진&캡션` : 본문 내 이미지와 사진 설명 캡션 삽입
  - `+ 구분선` : 섹션 구분 라인 삽입
* **실시간 미리보기 (Live Preview)**: 작성 중인 기사가 잡지 리더에서 어떻게 보일지 탭 전환만으로 즉시 확인 가능
* **전체 기사 관리 & 백업/복원**:
  - 작성된 기사의 수정, 삭제, 커버 기사 변경
  - `JSON 다운로드`: 작성한 기사 데이터를 파일로 안전하게 백업
  - `JSON 불러오기`: 다른 부원이 작성한 기사 JSON 파일을 손쉽게 취합
  - `기본 샘플 복원`: 언제든 초기 데모 기사로 리셋 가능
  - `LocalStorage 자동 저장`: 브라우저를 새로고침하거나 닫았다가 다시 열어도 데이터가 안전하게 유지됩니다.

### 2. 📖 디지털 매거진 리더 (Magazine Viewer)
* **Hero 커버 스토리**: 잡지 표지 메인 기사를 웅장한 비주얼과 헤드라인으로 상단에 배치
* **카테고리 필터 & 실시간 검색**: 카테고리 탭 및 제목/기자명/태그 실시간 검색
* **고품격 에디토리얼 레이아웃**:
  - Nanum Myeongjo(나눔명조)와 Pretendard 서체를 조합한 매거진 타이포그래피
  - 문단의 첫 글자를 크고 우아하게 띄우는 드롭캡(Drop Cap) 스타일
  - 잡지 인용구 블록 및 캡션 레이아웃
* **독서 편의 기능**:
  - `A- / A+` 본문 폰트 크기 실시간 확대/축소
  - 링크 공유 (클립보드 원클릭 복사)
  - 인쇄 모드 (Print CSS 적용으로 잡지 책자처럼 깔끔하게 출력/PDF 저장 가능)

---

### 3. 🎄 연말 특별 인터랙티브 기능
* **❄️ 겨울 설경 효과**: 캠퍼스 위로 조용히 흩날리는 부드러운 눈송이 캔버스 애니메이션 (상단 배너에서 ON/OFF 토글 가능)
* **💌 2026 연말 롤링페이퍼 & 소원 보드**: 
  - 올 한 해 수고한 동기, 선후배에게 따뜻한 응원의 한마디나 2027년 새해 소원을 남기는 인터랙티브 스티커 메모 보드
  - 5가지 파스텔 컬러 메모지 지원 및 로컬 저장 연동
  - **✏️ 메모 수정 기능**: 각 스티커 메모 상단의 `[✏️ 수정]` 버튼을 눌러 작성자, 메모지 색상, 메시지 본문을 언제든 수정 가능
  - **🗑️ 메모 삭제 기능**: 불필요한 메모를 확인 후 즉시 삭제 가능

## 🚀 실행 방법

별도의 서버 설치나 복잡한 빌드 과정이 전혀 필요하지 않습니다.

1. `index.html` 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 웹 브라우저에서 바로 실행합니다.
2. 우측 상단의 `[기사 작성 / 제작 폼]` 버튼을 눌러 기사를 추가하거나 기존 기사를 수정할 수 있습니다.

## 🌐 GitHub Pages 무료 배포 방법

1. 현재 레포지토리에 커밋 & 푸시합니다:
   ```bash
   git add .
   git commit -m "feat: 인덕대학교 언론부 2026 연말 매거진 및 기사 제작 폼 완성"
   git push origin main
   ```
2. GitHub 저장소의 **Settings > Pages** 메뉴로 이동합니다.
3. **Build and deployment > Branch**에서 `main` 브랜치를 선택하고 `Save`를 누르면 수 분 내에 무료 웹사이트 주소(`https://<아이디>.github.io/<저장소이름>/`)가 생성됩니다.
